# 奶家

让奶蛙、奶蛋、奶鼠、奶狗和奶鸡陪伴你的桌面。奶家是一款本地运行的 Windows 桌宠，支持角色互动、自由拖动、多角色切换和分身。

当前版本：2.2.2 · 支持 Windows 10 / 11 · 需要 .NET Framework 4.x

## 下载

仓库已按完整的用户端目录提供程序、角色与声音素材。

1. 下载整个仓库目录的zip。
2. 完整解压后，进入 **NaiJia-main** 文件夹，双击 **奶蛙桌宠.exe** 启动。
3. 请保留程序旁的“角色”和“品牌”文件夹。

也可以从 [Releases 下载 v2.2.2 Windows 文件夹版](https://github.com/yugh6/NaiJia/releases/download/v2.2.2/NaiJia-v2.2.2-Windows.zip)。在发行页面中请选择名称含 Windows 的 ZIP。`SHA256SUMS.txt` 对应该版本发布包。

本仓库提供完整的成品运行文件和使用说明，源码不随包发布。

## 开始使用

1. 将发布包完整解压到一个文件夹。
2. 双击 **奶蛙桌宠.exe** 启动。
3. 按住鼠标左键可拖动桌宠；右键点击桌宠可打开菜单。

请保持程序与“角色”“品牌”文件夹的位置关系，移动程序时一并移动整个文件夹。奶家无需联网，所有角色统一使用固定尺寸。

## 基本操作

| 操作 | 功能 |
| --- | --- |
| 按住左键拖动 | 将桌宠移动到喜欢的位置，支持多屏。 |
| 鼠标悬停 | 显示角色两侧的切换箭头。 |
| 点击左右箭头 | 按顺序切换五个角色。 |
| 右键 → 当前角色 | 从列表中选择角色。 |
| 右键 → 复原 | 停止当前动作，恢复角色的初始状态。 |
| 点击菜单外部 | 收起菜单及角色列表。 |

下文中的单击、双击均指鼠标左键。右键菜单会显示当前角色可用的动作。

## 角色玩法

| 角色 | 单击 | 双击 | 菜单玩法 |
| --- | --- | --- | --- |
| 奶蛙 / 奶粉 | 戳肚子，产生回弹反馈。 | 捧腹大笑。 | 变奶粉 / 变奶蛙、叶问蹲、溜达。 |
| 奶蛋 | 说“安迪”。 | 破壳孵化，随后切换为奶鸡。 | 喝奶。 |
| 奶鼠 | 显示 Hello 姿势，再单击复原。 | 跳舞。 | Hello、奶鼠跳舞。 |
| 奶狗 | 狗叫。 | 执行“拉屎”动作。 | 狗叫、拉屎。 |
| 奶鸡 | 鸡叫。 | 下蛋，随后切换为奶蛋。 | 鸡叫、下蛋。 |

奶粉是奶蛙的粉色形态，两种形态支持相同互动。奶蛙大笑期间或笑倒后，单击会立即进入“叶问蹲”，再单击恢复初始状态。鼠标悬停在奶蛋身上时，奶蛋会轻轻摇晃。

### 溜达与方向控制

选择奶蛙或奶粉，在右键菜单中点击“溜达”。角色会在所在屏幕左右行走，到达边缘后转身折返。

- 按 **← / →** 可实时改变方向，松开后继续沿当前方向行走。
- 单击桌宠即可停止溜达并恢复站姿。
- 打开菜单时暂停行走，收起后继续；拖动、复原、切换角色或全屏隐藏会停止溜达。
- 多只桌宠同时溜达时，方向键控制最近操作的那一只。

## 分身与集合

| 菜单选项 | 功能 |
| --- | --- |
| 分身 | 在当前桌宠旁创建一只相同角色，继承当前配色和开关设置。每只桌宠之后可独立切换角色、互动、拖动和退出。 |
| 归一 | 关闭其他桌宠，只保留当前这一只。桌面上有多只桌宠时显示此选项。 |
| 奶家人集合 | 保留当前桌宠，关闭其他桌宠，再向四周展开其余四个角色，组成五角色集合。 |

奶粉按奶蛙计算角色，因此以奶粉发起集合时，另外四位是奶蛋、奶鼠、奶狗和奶鸡。集合配音受发起桌宠的声音开关控制。

## 菜单设置

**声音、总在最上面、全屏时自动隐藏**通过菜单右侧的开关操作。点击文字不会切换；操作开关后菜单保持打开。

- **声音**：控制当前这只桌宠所有角色的音效。中途关闭声音，动画继续；重新开启后按当前进度接回声音，已结束的音轨不会重播。喝奶、破壳孵化、下蛋和奶狗“拉屎”动作为无声动作。
- **总在最上面**：开启后，桌宠保持在普通应用窗口上方；关闭后可被其他窗口遮挡。
- **全屏时自动隐藏**：所在屏幕的前台应用进入全屏时隐藏桌宠，退出全屏后恢复。普通最大化和其他屏幕的全屏应用不会触发。
- **回到屏幕右下角**：将当前桌宠移回鼠标所在屏幕的右下角。
- **打开使用说明**：查看完整操作指南。
- **退出桌宠**：关闭当前这一只。关闭最后一只时，程序退出。

各只桌宠的开关设置相互独立；同一只桌宠切换角色时会保留设置。

## 常见问题

**找不到桌宠了？** 先将鼠标移到希望显示桌宠的屏幕，再重复运行程序，或双击任务栏通知区域中的奶家图标。最近操作的桌宠会回到该屏幕右下角。若正在使用全屏应用，可从托盘菜单关闭“全屏时自动隐藏”。

**动作没有声音？** 检查当前桌宠的声音开关及系统音量。部分动作为无声动作；动作或音轨已经结束时，开启声音不会重新播放。

**怎样关闭所有分身？** 在任一桌宠菜单中选择“归一”，然后选择“退出桌宠”。

**程序提示素材缺失？** 请重新完整解压发布包，并确认“角色”“品牌”文件夹与程序放在一起。
